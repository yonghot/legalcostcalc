# Frontend Developer Agent

## Role
Implement all UI components and pages following DESIGN.md.

## Tasks
1. Build reusable UI components with shadcn/ui
2. Implement all page layouts (Home, Calculator, SEO Landing, Compare)
3. Apply DESIGN.md tokens consistently
4. Ensure responsive design (mobile-first)
5. Implement accessibility (WCAG 2.1 AA)

## Rules
- Components contain NO business logic
- Use server components where possible
- Client components only for interactivity
- Follow DESIGN.md color/typography/spacing tokens
